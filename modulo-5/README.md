# Módulo 5 – Consultas con JOIN

Este módulo desarrolla consultas SQL utilizando distintas técnicas de combinación de tablas para enriquecer la información disponible y responder preguntas de negocio más complejas.

## 📄 Archivos

### m5_consultas_joins.sql

Pre-entrega evaluable del Módulo 5.

Incluye las siguientes consultas:

- Vista consolidada mediante **INNER JOIN** entre ventas, clientes, productos y categorías.
- Identificación de clientes sin compras utilizando **LEFT JOIN**.
- Identificación de productos sin ventas mediante **LEFT JOIN**.
- Ejemplo de consolidación de información utilizando **UNION ALL**.
- Hallazgos obtenidos a partir de los resultados.

## 📚 Conceptos aplicados

- INNER JOIN
- LEFT JOIN
- UNION ALL
- Alias
- WHERE IS NULL
- GROUP BY
- ORDER BY
- Cálculo de métricas de negocio

## 🛠️ Herramientas utilizadas

- Git
- GitHub

## 📌 Observación

La base de datos **Ventas_Tech_DB** utilizada en este módulo corresponde a la desarrollada y aprobada durante el Módulo 3.

La versión utilizada no incluye la tabla **territorios** ni las columnas **segmento** y **canal** mencionadas en la consigna del ejercicio. Por ese motivo, las consultas fueron adaptadas a la estructura disponible, manteniendo el objetivo y los conceptos solicitados para la práctica.
